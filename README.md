# Duy P. Nguyen Academic Website

A simple static academic website designed for GitHub Pages.

## Files

- `index.html`: main page
- `stylesheet.css`: responsive styling
- `images/`: profile and project images
- `CV-Eng.pdf`: add your current CV here

## Before publishing

1. Replace `images/profile.jpg` with your portrait.
2. Replace `images/pd1.png` with your favicon.
3. Replace the three project placeholder images:
   - `images/climate-health.jpg`
   - `images/pangasius.jpg`
   - `images/active-travel.jpg`
4. Add your CV as `CV-Eng.pdf`.
5. Replace any `href="#"` placeholder links with real project or paper links.
6. Review the News dates and research descriptions.

## Publish on GitHub Pages

Upload the files to the root of your `nguyenphd.github.io` repository, commit,
and push to the default branch. GitHub Pages should deploy automatically.
